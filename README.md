# ThinkLab
> 面向大学生及对哲学思考感兴趣的年轻人的哲学 AI Web Agent。

## 项目简介
产品以现实生活中的困惑为切入点，通过多种哲学视角分析、交互式探索和结构化思考记录，帮助用户理解问题的不同方面，并逐步形成自己的判断。

## 产品定位
ThinkLab 不仅提供哲学知识和观点，还强调用户的主动参与，希望将哲学从抽象的理论知识转化为理解现实问题、探索个人价值观的思考工具。
