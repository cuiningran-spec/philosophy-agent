# problem_definition.md
> 项目名称：哲学代理人 philosophy-agent
> 产品定位：帮助用户从多个哲学视角理解现实问题，并通过自主选择探索方向，形成个人思考的哲学 AI Agent。
> MVP核心功能：
> 1. 用户输入一个现实问题。
> 2. Agent 给出三个有区别的哲学视角。
> 3. 用户选择一个视角，继续进行一次针对性探索。
> 4. 页面整理本次思考结果。

## 5W1H 问题定义
### 1. Why（为什么做）
人们面对现实生活中的各类问题时，常常局限于单一角度思考，缺少多元哲学视角来剖析问题。普通AI容易直接给出结论，代替用户思考。本项目开发哲学AI Agent，不直接提供标准答案，引导用户自主选择思考方向，借助不同哲学流派的视角分析现实问题，锻炼独立思辨能力。

### 2. What（做什么，解决什么问题）
本产品是哲学AI Agent。用户输入现实问题后，Agent自动提供3种不同的哲学分析视角；用户挑选其中一个视角继续深入探讨；对话结束后，自动汇总整理本次完整思考过程。
产品目标不是直接给答案，而是引导用户借助哲学工具，构建属于自己的思考结论。

### 3. Who（为谁服务）
目标用户：哲学爱好者、学生，以及希望用哲学思维分析现实问题、锻炼多角度思辨能力的人群。

### 4. When（使用时机）
当用户遇到现实难题、社会议题，想要跳出固有思维，希望从哲学层面多角度分析问题时使用；也可用于哲学课程思辨练习、思维训练。

### 5. Where（使用场景）
网页端访问，电脑浏览器即可使用，适用于自习、课余思考、课题思辨练习等场景。

### 6. How（如何实现MVP）
1. 前端页面：提供输入框提交现实问题，展示3个哲学视角选项，支持用户选择视角，最后展示整理后的思考总结。
2. AI Agent核心：内置多哲学流派提示词，接收用户问题，生成3个差异化哲学视角；接收用户选中的视角，继续针对性深度对话。
3. 后端服务：处理前后端交互，调用大模型接口，记录对话流程，最后自动整合对话内容，生成本次思考报告。
4. 基础校验：做简单内容过滤，保证输出哲学视角区分度，避免观点重复。

## 产品描述
哲学代理人是一款哲学AI Agent。用户输入现实问题，系统会输出三种不同的哲学视角供用户挑选；用户选定一个视角后继续深入探究；最后页面自动整理全部思考过程。产品核心目标是引导用户自主探索，借助多元哲学视角分析现实问题，形成个人独立思考，而不是直接给出固定答案。
